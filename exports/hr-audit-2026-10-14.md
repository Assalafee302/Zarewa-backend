# HR audit — Zarewa ERP (2026-10-14)

This audit is read-only: no code, data or push changes. It covers code in `Zarewa-backend-main` and `Zarewa-frontend-main`, both on branch `fix/controls-phase3`. Usage numbers come from the local MySQL schema `zarewa_phase2_rehearsal` (SELECT only).
Note: Phase 2 corrections were applied to this schema earlier today. Those touch coils, receipts and refunds, not HR tables. Columns marked "updated today" on `hr_departments`, `hr_designations` and `hr_salary_matrix` come from migrate/seed runs on the rehearsal schema, not from user activity.

## 6. Payroll calculation

### 6.1 Gross → net, step by step (`computePayrollRun`, `server/hrOps.js:4424–4656`)

| Step | Rule | Code |
|---|---|---|
| 1. Who is paid | Active login users (`app_users.status='active'`) whose `payroll_group` ∈ {branch_ops, hq_admin, mining}. Scholarship, domestic and chairman staff are excluded. | `hrOps.js:4453–4460`, `shared/lib/hrStaffCohorts.js:143` |
| 2. Monthly salary | Approved **salary structure version** for designation + branch as at period end; if none, **profile base + housing + transport**. Today no version exists, so every line uses the profile. | `hrOps.js:4530–4539` |
| 3. Allowances | Only housing and transport (profile columns), added in step 2. No other allowance types. | `hrOps.js:4534–4537` |
| 4. Absences / lateness | Branch_ops only. Daily rate = **base ÷ 22**. (Absent days − approved-leave working days − approved exceptions) + (late days − exceptions), each × daily rate. **A late day costs a full day.** Source: attendance uploads (0 rows), so ₦0 today. | `hrOps.js:3911–3953` |
| 5. Year-end bonus | December runs only: salary × `halfMonthBonusRate` (0.5). | `hrOps.js:4549` |
| 6. Gross | salary + bonus − attendance deduction | `hrOps.js:4550` |
| 7. PAYE | **Fixed ₦ amount typed on the staff profile (`paye_tax_ngn`)**, no calculation. `paye_tax_ngn` is empty for all 22 profiles → PAYE = ₦0 on every line. | `hrOps.js:4551–4552`; UI text `HrPayeTaxPension.jsx:696` |
| 8. Pension (employee) | 8% × **gross** (including bonus, after absence deduction) unless `statutory.pensionExempt`. Employer 10% × gross is recorded but not deducted. | `hrOps.js:4558–4559`, `hrBusinessRules.js:43–44` |
| 9. NHF | **Not implemented** (no field, no deduction). | — |
| 10. NHIS | Profile has `nhis_deduction_ngn`/`nhis_provider` (always empty); **not used** in the calculation. | — |
| 11. Loans | Active staff obligation accounts (instalment, capped at outstanding); else approved `hr_requests` loans with `deductionsActive`. | `hrOps.js:3720–3752` |
| 12. Incident recoveries | Active recovery schedules (staff obligations of kind recovery). | `hrIncidentRecoveryOps.js:179` |
| 13. Disciplinary deduction | From branch assessment report lines (0 rows); legacy fixed amount only if env `HR_LEGACY_DISC_DEDUCTION=1`. | `hrSalaryStructureOps.js:328`, `hrOps.js:4561` |
| 14. Overtime | **Not in payroll.** OT is paid separately by the cashier (`ot_requests`) or booked as an expense. | `otApi.js:408` |
| 15. Net | gross − PAYE − pension − (loans + recoveries + discipline). Net = 0 if salary status is held/suspended. | `hrOps.js:4568–4573` |
| 16. Employer levies | ITF 1% and NSITF 1% of total gross, on the run header. | `hrOps.js:4628–4629` |
